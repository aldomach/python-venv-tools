# Roadmap

## 1.2 — Dependencias y compilación
Implementado: editor, escaneo AST, selección de candidatos, comparación, instalación/actualización, freeze, resolución uv opcional. Archivos de build Windows y portable. Pendiente: prueba de compilación Windows y UI nativa, mayor cobertura de requirements complejos y selección gráfica de versiones de sugerencias.

## 1.3 — Administración integral
Registro de entornos existentes, búsqueda de proyectos, inventario completo de intérpretes, instalación de Python (evaluar uv python), clonado mediante recreación y lock (no copiar venv), cambio de nombre seguro, eliminación con confirmación, tamaño y limpieza de caché.

## 1.4 — Productividad
Plantillas, PyPI, paquetes actualizables, instalación desde Git/archivos, terminal activada, historial persistente, asistente de conflictos, accesos directos y navegación de UI por secciones.

## 2.0 — Ampliación
pyproject.toml, motores Poetry/Conda/PDM/Hatch, temas, respaldo y restauración, varios entornos, gestión central de intérpretes y arquitectura modular. Validar alcance y licencias antes de implementar.
